Exercice 1 : Manipulation de la commande ls
Depuis le répertoire personnel (home directory, ~) :

a. Format condensé :
   $ ls

b. Format long :
   $ ls -l

c. Affichage des fichiers cachés :
   $ ls -a

d. Affichage en ordre alphabétique inverse :
   $ ls -r

e. Format long, avec fichiers cachés, triés du plus récent au plus ancien :
   $ ls -lat

f. Format long, avec fichiers cachés, triés du plus ancien au plus récent :
   $ ls -latr


Exercice 2 : Effet de la commande cd sans paramètre
Commande :
   $ cd
Effet :
   Quelle que soit la position actuelle dans l'arborescence du système de fichiers,
   la commande `cd` exécutée sans aucun argument ramène systématiquement l'utilisateur
   à la racine de son répertoire personnel (homedir, correspondant à la variable $HOME ou '~').
   Exemple de test :
   $ cd /usr/share/doc
   $ pwd   # Affiche : /usr/share/doc
   $ cd
   $ pwd   # Affiche : /home/<utilisateur>


Exercice 3 : Création et déplacement de fichiers
a. Création en une seule commande des fichiers demandés :
   $ touch annee1 annee2 Annee3 f1.txt f2.txt f11.txt

b. Création du répertoire Year et déplacements :
   - Création du répertoire :
     $ mkdir Year
   - Déplacement sans globbing des fichiers annee1, annee2, Annee3 vers Year :
     $ mv annee1 annee2 Annee3 Year/
   - Déplacement avec globbing de f1.txt et f2.txt :
     $ mv f[12].txt Year/
     (ou : $ mv f?.txt Year/)


Exercice 4 : Création d'une hiérarchie de répertoires
Création sous le dossier personnel de 'system' puis de 'system/tp1' en une commande :
   $ mkdir -p ~/system/tp1
(Depuis le homedir : $ mkdir -p system/tp1)


Exercice 5 : Suppression avec rmdir
Commande exécutée :
   $ rmdir ~/system
Constat :
   La commande échoue avec l'erreur : "rmdir: failed to remove 'system': Directory not empty".
   En effet, `rmdir` ne peut supprimer que des répertoires strictement vides. Comme 'system'
   contient le sous-répertoire 'tp1', sa suppression directe par rmdir est refusée.


Exercice 6 : Suppression et recréation d'arborescence
- Suppression récursive du dossier 'system' :
   $ rm -r ~/system

- Création en une seule commande des répertoires system, system/tp1 et system/tp2 :
   $ mkdir -p ~/system/tp1 ~/system/tp2
   (ou en utilisant l'expansion d'accolades : $ mkdir -p ~/system/{tp1,tp2})


Exercice 7 : Renommage d'un répertoire
Renommer 'system' en 'test' (depuis le répertoire parent / homedir) :
   $ mv ~/system ~/test


Exercice 8 : Copie d'un fichier depuis /bin vers test/tp1
(Exemple avec le binaire /bin/ls)

a. Copie effectuée en se plaçant dans le répertoire /bin :
   $ cd /bin
   $ cp ls ~/test/tp1/

b. Copie effectuée en se plaçant dans le répertoire test/tp1 :
   $ cd ~/test/tp1
   $ cp /bin/ls .

c. Copie effectuée depuis le homedir (~), en utilisant des chemins absolus :
   $ cd ~
   $ cp /bin/ls /home/$USER/test/tp1/

d. Copie effectuée depuis le homedir (~), en utilisant des chemins relatifs :
   $ cd ~
   $ cp /bin/ls test/tp1/


Exercice 9 : Suppression de plusieurs répertoires en une commande
Depuis le répertoire personnel :
   $ rm -r test/tp1 test/tp2
(Si les répertoires sont vides, on peut également faire : $ rmdir test/tp1 test/tp2)


Exercice 10 : Déplacement d'arborescence
Pour déplacer toute l'arborescence rep3 sous rep2 (en se trouvant dans homedir) :
   $ mv rep3 rep2/
L'arborescence devient alors rep2/rep3/...


Exercice 11 : Copie sélective avec globbing vers /tmp
Pour copier tous les fichiers fX.txt (où X est un chiffre compris entre 0 et 5) :
   $ cp f[0-5].txt /tmp/


Exercice 12 : Filtrage avancé par globbing
Fichiers présents dans rep2 :
f1A.txt, f1a.txt, f1a.aux, f11.txt, f1a.TXT, f2A.txt, f2a.txt, f21.txt, f2a.TXT, f2a.aux

Positionnement préalable :
   $ cd rep2

a. Tous les fichiers finissant par l'extension .txt et .TXT :
   $ ls *.{txt,TXT}
   (ou : $ ls *.[tT][xX][tT])

b. Tous les fichiers commençant par f1, dont le 3ème caractère n'est pas un chiffre :
   $ ls f1[!0-9]*
   (ou avec syntaxe POSIX : $ ls f1[![:digit:]]*)

c. Tous les fichiers dont le 3ème caractère est une lettre minuscule :
   $ ls ??([a-z])*  ou plus simplement : $ ls ??[a-z].*
   (De manière générique sur la structure du nom : $ ls ??[[:lower:]]*)

d. Tous les fichiers ne finissant pas par l'extension .aux :
   Pour utiliser la négation d'un motif, activer l'extglob de bash si nécessaire :
   $ shopt -s extglob
   $ ls !(*.aux)


SECTION 7 : SYNTHÈSE

7.1 Exercice A
1. Déterminer le répertoire courant :
   $ pwd

2. Vérifier la présence de fichiers et répertoires :
   $ ls -l
   (Les lignes commençant par la lettre 'd' correspondent à des répertoires,
    celles commençant par '-' correspondent à des fichiers réguliers).

3. Entrer du texte dans un fichier nommé "Mon_fichier" :
   $ touch Mon_fichier
   $ echo "Contenu du fichier" > Mon_fichier
   (ou via un éditeur : nano Mon_fichier, ou gnome-text-editor Mon_fichier &)

4. Lister le contenu de "Mon_fichier" :
   $ cat Mon_fichier

5. Lister le répertoire courant :
   $ ls

6. Lister les répertoires /bin et /dev :
   $ ls /bin /dev

7. Créer sous votre répertoire deux sous-répertoires "Source" et "Data" :
   $ mkdir Source Data

8. Se positionner sous "Source" :
   $ cd Source

9. Lister le répertoire courant :
   $ ls

10. Revenir sous le répertoire de départ et détruire "Source" :
    $ cd ..
    $ rmdir Source   (ou $ rm -r Source)

11. Créer un deuxième fichier nommé "Mon_fichier_2" :
    $ touch Mon_fichier_2

12. Copier chaque fichier en nom_de_fichier.old :
    $ cp Mon_fichier Mon_fichier.old
    $ cp Mon_fichier_2 Mon_fichier_2.old

13. Créer un répertoire "Old" :
    $ mkdir Old

14. Déplacer les fichiers avec l'extension .old vers le répertoire "Old" :
    $ mv *.old Old/

15. Effacer tous les fichiers créés dans Old sans effacer le répertoire Old :
    $ rm Old/*


7.2 Exercice B : Exploration de l'arborescence Linux
1. Indiquer dans quel répertoire on se trouve :
   $ pwd

2. Aller dans /usr/share/doc puis vérifier le chemin courant :
   $ cd /usr/share/doc
   $ pwd

3. Remonter dans le répertoire parent puis vérifier :
   $ cd ..
   $ pwd   # Résultat : /usr/share

4. Aller dans son répertoire personnel sans taper son chemin :
   $ cd

5. Retourner dans le répertoire précédent sans taper son chemin :
   $ cd -

6. Retourner dans son répertoire personnel et lister les fichiers présents :
   $ cd
   $ ls

7. Lister tous les fichiers (y compris les fichiers cachés) :
   $ ls -a

8. Afficher de façon détaillée le contenu de /usr sans changer de répertoire :
   $ ls -l /usr

9. Afficher l'arborescence de fichiers contenue dans /var sans changer de répertoire :
   $ ls -R /var
   (ou si installé : $ tree /var)

10. Afficher en format long le contenu de /var/log classé du plus ancien au plus récent :
    $ ls -ltr /var/log


7.3 Exercice C : Répertoires et consultation de fichiers
1. Aller dans son répertoire personnel :
   $ cd ~

2. Créer un répertoire nommé CommandesLinux :
   $ mkdir CommandesLinux

3. Aller dans le répertoire CommandesLinux :
   $ cd CommandesLinux

4. Créer l'arborescence cours1/cours2/cours3/cours4 :
   $ mkdir -p cours1/cours2/cours3/cours4

5. Lister le contenu du répertoire courant de façon récursive :
   $ ls -R

6. Supprimer le répertoire cours1 :
   $ rmdir cours1
   -> Constat : Impossible car le dossier n'est pas vide (Directory not empty).

7. Supprimer l'arborescence cours1/cours2/cours3/cours4 puis vérifier avec ls -R :
   $ rm -r cours1
   $ ls -R

8. Créer l'arborescence suivante dans CommandesLinux :
   |-- couleur
   |   `-- froide
   `-- forme
       |-- angle
       `-- courbe

   Commandes :
   $ mkdir -p couleur/froide forme/angle forme/courbe

9. Copier le fichier /etc/services dans CommandesLinux :
   $ cp /etc/services .

10. Propriétaire et date de dernière modification de la copie :
    $ ls -l services
    -> Propriétaire : L'utilisateur courant (celui qui a effectué la copie cp).
    -> Date de modification : La date et l'heure exactes de la copie (cp crée un nouveau
       fichier appartenant à l'utilisateur courant avec le timestamp actuel, sauf utilisation de l'option -p).

11. Créer les fichiers vides rond.txt, triangle.txt, carre.txt, rectangle.txt, vert.txt, bleu.txt :
    $ touch rond.txt triangle.txt carre.txt rectangle.txt vert.txt bleu.txt

12. Déplacer rond.txt dans forme/courbe/ et triangle.txt, carre.txt, rectangle.txt dans forme/angle/ :
    $ mv rond.txt forme/courbe/
    $ mv triangle.txt carre.txt rectangle.txt forme/angle/

13. Déplacer vert.txt et bleu.txt dans couleur/froide/ :
    $ mv vert.txt bleu.txt couleur/froide/

14. Aller dans couleur/ et afficher le contenu de façon récursive :
    $ cd couleur
    $ ls -R

15. Copier le répertoire couleur sous le nom chaude :
    Est-ce possible ? Oui, à condition d'effectuer une copie récursive avec l'option -r :
    $ cd ~/CommandesLinux
    $ cp -r couleur chaude

16. Dans chaude, renommer bleu.txt en rouge.txt et vert.txt en jaune.txt :
    $ cd chaude/froide
    $ mv bleu.txt rouge.txt
    $ mv vert.txt jaune.txt

17. Remonter dans CommandesLinux et renommer couleur en peinture :
    $ cd ~/CommandesLinux
    $ mv couleur peinture
    -> Est-il besoin de spécifier une option particulière à mv ?
       Non, aucune option n'est nécessaire. La commande `mv` renomme et déplace les
       dossiers de manière atomique sans option récursive (contrairement à `cp` ou `rm`).

18. Lister la totalité de l'arborescence contenue dans CommandesLinux :
    $ ls -R ~/CommandesLinux

19. Afficher le contenu du fichier /etc/issue :
    $ cat /etc/issue
    -> Contenu : Ce fichier contient le nom et la version du système d'exploitation / distribution
       Linux installée (par exemple "Ubuntu 22.04.2 LTS \n \l"), affiché comme message d'accueil
       avant l'invite de connexion (login) sur les consoles tty.
